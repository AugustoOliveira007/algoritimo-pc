Aula 10:

Exercícios:

1- Desenvolva um programa que leia o peso do pacote e utilize a função: float calcular_frete(float peso); para calcular e retornar o valor do frete.

2- Crie a função que receba os dois valores e troque seus conteúdos.

3- Desenvolva um programa em C que solicite duas notas de um aluno, calcule a média e informe o resultado, utilizando funções. Permita que o programa seja executado enquanto o usuário possuir notas a serem digitada!

4- Desenvolva um programa em C que: ▪ leia a largura (em metros); ▪ leia o comprimento (em metros); ▪ utilize uma função calcularArea() para calcular a área; ▪ exiba o resultado; ▪ permita calcular quantas áreas o usuário precisar.

5- Crie uma estrutura Aluno contendo: rgm nota1 nota2 media Implemente: void calcular_media(Aluno *aluno); A função deverá atualizar o campo media.
