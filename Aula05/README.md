Aula 5:

Projeto 1 Arena Tech

Contexto do desafio: A turma foi convidada a organizar a Arena Tech, uma pequena maratona gamer no campus. Antes de confirmar o evento, a equipe precisa estimar a quantidade de times, o consumo de energia, os custos envolvidos e verificar se a infraestrutura disponível é suficiente. Além de realizar os cálculos, o programa deverá analisar os resultados e emitir um diagnóstico sobre a viabilidade do evento.
